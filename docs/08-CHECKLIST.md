- [ ] `IR_VERSION` 版本机制就位，加载不兼容版本时给出明确升级提示
- [ ] `.mcir` 序列化往返测试通过（保存 → 加载 → 逐字段相等）
- [ ] `Stage` / 各 `*Adapter` 协议定义完成
- [ ] 配置系统五层覆盖生效（默认 → 用户 → 项目 → 环境 → 参数）
- [ ] 内容哈希缓存可用，命中/未命中行为正确

### 调色板
- [ ] 从 `.jar` 提取纹理并解析 `models`/`blockstates` 继承链
- [ ] `(方块, 面) → Lab 均值 / 方差 / 频率能量` 表生成
- [ ] 🔒 平均色在**线性空间**计算（非 gamma 空间）——有单元测试守护
- [ ] 生物群系着色（草/叶/水）参数化处理
- [ ] 方块属性表：重力 / 需支撑 / 亚体素形状 / tier / 是否全立方体
- [ ] 调色板按 MC 版本 + 资源包哈希缓存，多版本可共存

### E1 色域实验
- [ ] 🔒 **E1 报告产出**：最近邻距离场、覆盖率、最难表达色相
- [ ] 报告以 HTML 形式可分享，含热力图
- [ ] 🔒 **已根据 E1 结果复核并调整 PRD 的质量承诺与 ΔE₀₀ 阈值**
- [ ] 实测的"可用作颜色源的方块数"已替换文档中的估计区间（250–400）

### 导出链路
- [ ] `.litematic` 导出并可被 Litematica 读取
- [ ] `.schem` 导出符合 Sponge Schematic v3 规范
- [ ] `.nbt` 导出，且超过 48³ 时正确报错或自动切分
- [ ] 每种格式往返读写逐方块一致
- [ ] 材料清单 CSV 输出
- [ ] `provenance` 完整写入

### 🔒 游戏内验证
- [ ] 🔒 **手工构造的体素数组导出后，在真实 MC 客户端加载并放置成功**
- [ ] 🔒 放置结果与预期逐方块一致（人工核对 + 录屏存档）
- [ ] 测试覆盖：全立方体 / 楼梯 / 台阶 / 重力方块 / 需支撑方块

### 渲染验证回路

- [ ] 渲染结果可与参考视图计算 LPIPS/DISTS
- [ ] 内置轻量预览渲染器（**不依赖游戏纹理**，用纯色块）

### 工程基础
- [ ] CI：单元测试 + 类型检查 + lint
- [ ] 🔒 CI 依赖方向检查（防止违反 AR-1 / 反向依赖）

- [ ] `mcvox` 或替代包名已确认可用（Q4）

## G2 · Phase 2 L3 深化出口

### MRF 与求解
- [ ] 成对项 `ψ` 满足图割可解性条件（Kolmogorov & Zabih 判据）
- [ ] 方块共现统计从 ≥1000 个真实建筑得出
- [ ] α-expansion 求解器可用，32³ 分块 + 重叠 4 体素
- [ ] 🔒 代价量化为 int32（消除浮点非确定性）
- [ ] 方块碎片化显著下降（连通块平均尺寸对比 Phase 1 有量化提升）

### 亚体素几何
- [ ] 形状模板库：stairs（40 变体）/ slab / carpet / snow_layer
- [ ] 替换前后做几何代价验证，不降低误差则保持全方块
- [ ] 🔒 屋顶/球面 Hausdorff 误差相比纯全方块下降 ≥30%
- [ ] 🔒 亚体素替换不破坏结构完整性（有专门的修复 pass 校验）

### 物理与预算
- [ ] 悬空检测 + 连通分量分析
- [ ] 重力方块支撑校验与替换
- [ ] 需附着方块的附着面校验
- [ ] 🔒 **物理合法率 100%**
- [ ] 材料预算约束可用，超预算时按 tier 降级替换
- [ ] 放置顺序生成（先支撑后附着）

### 风格与性能
- [ ] ≥4 套风格映射表，产出目视差异明显
- [ ] 🔒 N=256 端到端 < 3 min
- [ ] 🔒 峰值显存 ≤ 22 GB
- [ ] 性能基准入库，防止悄悄劣化
